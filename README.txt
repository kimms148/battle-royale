GitHub에 올리면 Render가 자동으로 다시 배포해요.

배틀로얄 (1인칭 서바이벌) 실행 방법
==================================

[처음 한 번]
1. Node.js 설치: https://nodejs.org 에서 LTS 버전을 받아 설치해요.
2. 이 폴더(배틀로얄)에서 주소창에 cmd 를 입력하고 엔터 → 검은 창이 열려요.
3. npm install   (three, ws 두 개를 받아요. 1분 정도)

[게임 켜기]
1. 같은 검은 창에서  npm start
2. 창에 이런 줄이 나와요.
     배틀로얄 서버 실행 중: http://localhost:3000
     같은 와이파이 친구: http://192.168.x.x:3000
3. 나는 크롬에서 http://localhost:3000 접속
4. 같은 와이파이(같은 집, PC방 등) 친구는 두 번째 주소로 접속
5. 다 들어오면 아무나 [게임 시작]

※ 윈도우 방화벽 창이 뜨면 "허용"을 눌러야 친구가 들어올 수 있어요.

[멀리 있는 친구와 하기] 셋 중 하나
A. 공유기 포트포워딩: 공유기 관리 페이지에서 TCP 3000번을 이 PC로 열고,
   친구는 http://내공인IP:3000 으로 접속. 핑이 가장 낮아요(한국 안이면 보통 10~30ms).
B. Render(무료): GitHub에 이 폴더를 올리고 Render에서 Web Service 생성
   - Region: Singapore (한국에서 가장 가까움, 핑 약 60~90ms)
   - Build Command: npm install
   - Start Command: npm start
   - 무료 플랜은 15분 동안 아무도 없으면 잠들고, 처음 접속할 때 깨어나는 데 1분 정도 걸려요.
C. 오라클 클라우드 무료 서버(서울/춘천 리전): 핑은 낮지만 설정이 조금 복잡해요.

[조작]
WASD 이동 / Shift 달리기(조준경 보면서 누르면 숨 참기) / Space 점프
마우스 시선 / 좌클릭 사격 / 우클릭 조준(누르고 있는 동안)
F 줍기 / 1~4 무기 (4를 다시 누르면 투척물 종류 변경) / X 집어넣기 / G 버리기
7 붕대 / 8 구급상자 / 9 의료용 키트 (쓰는 동안 손에 들고 있어요)
V 단검 (몸통 42, 머리 65) / 달리면서 C = 슬라이딩 / 맨손일 때 좌클릭 = 주먹 / 방탄복은 F로 주우면 바로 입어요 (1~3레벨, 몸통 피해 30·40·55% 감소, 머리는 못 막음)
로비의 [훈련장] = 혼자 연습 (모든 아이템, 거리별 표적, 허수아비, 실내 건물) / L 나가기
H 인벤토리 (총마다 조준경·총구·손잡이·탄창·개머리판 달기) / R 재장전 / B 사격 방식 / C 앉기 / Z 엎드리기 / Q·E 기울이기 / M 큰 지도(누르는 동안)

[맵과 AI 대전]
로비 방 설정에서 맵 5종(초원 마을, 사막 협곡, 설원 고지, 폐허 도시, 바위섬, 무작위)과 AI 봇 수(0~15명), 난이도를 골라요.
혼자 봇을 넣고 시작하면 AI 대전이에요. 사람이 모두 죽으면 그 판은 끝나요.

[키 설정]
로비의 [키 설정] 또는 게임 중 Esc → [키 설정]. 버튼을 누르고 원하는 키나 마우스 버튼(측면 버튼 포함)을 누르면 바뀌어요.

[투척물]
우클릭을 누르고 있으면 힘이 모이고(화면에 게이지와 궤적), 좌클릭으로 던져요. 우클릭 없이 좌클릭만 하면 중간 힘으로 던져요.
수류탄(4.2초)·섬광탄(2.4초)은 우클릭하는 순간 핀이 뽑히고 시간이 줄어요. 너무 오래 들고 있으면 손에서 터져요. 던진 뒤에도 남은 시간이 수류탄 위에 보여요.
화염병은 떨어진 곳에 8초 동안 불이 붙고, 불에 닿으면 불이 붙어 나와도 3초 동안 계속 타요.

[규칙]
- 맨손으로 시작해요. 건물 안과 컨테이너·상자 옆에 총, 탄, 조준경, 회복템, 투척물이 있어요.
- 총을 주울 때 그 총에 맞는 조준경이 가방에 있으면 자동으로 달려요.
- 파란 자기장 밖에 있으면 초당 체력이 깎이고, 단계가 지날수록 원이 작아지고 아파져요.
- 마지막 한 명이 남으면 끝. 12초 뒤 로비로 돌아가고 맵이 새로 만들어져요.
